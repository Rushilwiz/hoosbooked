# HoosBooked?

#### Centralized and intuitive room booking at the university.

> By: Rushil Umaretiya (frj2ka), James Greene (fqt9vv), Austin Song (rtx2nb), and James Crowell (pbd3rb)

### Development

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
